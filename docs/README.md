# Sextant documentation

Sextant is a Git client for Windows, macOS, and Linux. It uses the `git` already installed on the machine, including that installation's config, hooks, attributes, and credential helper.

- [Getting started](getting-started.md) covers download, install, update, the Git tools each platform needs, and opening repositories from WSL on Windows.
- [Configuration](configuration.md) covers every Settings page, where the files live, and a full `.json` formatting example with `jq`.
- [Working with Sextant](working-with-sextant.md) covers the day-to-day window: tabs, locations, history, commits, diffs, sync, conflicts, and LFS.
